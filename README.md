# Convite de Casamento — Clara & Luiz

Um convite de casamento digital elegante, moderno e interativo, projetado com estética artesanal de papelaria fina.

---

## Funcionalidades

- **Experiência Física de Carta/Envelope**: Animação de abertura de envelope 3D interativa ao tocar no selo de cera.
- **Papelaria Fina & Aquarela**: Texturas de papel nobre, manchas de aquarela orgânica e ramos botânicos delicados.
- **Tipografia Editorial**: Composição clássica e romântica com *Great Vibes* e *Montserrat*.
- **Pétalas Flutuantes Sutis**: Efeito de chuva suave de pétalas e poeira dourada em segundo plano.
- **Ações Rápidas**:
  - **Como Chegar** (Google Maps)
  - **Confirmar Presença** (WhatsApp RSVP)
  - **Lista de Presentes**
- **Mobile First**: 100% responsivo, calibrado para visualização perfeita em qualquer smartphone sem rolagem excessiva.

---

## Tecnologias

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS
- **Animações**: Framer Motion
- **Ícones**: Lucide React
- **Deploy**: Vercel

---

## Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
